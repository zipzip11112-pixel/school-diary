# Онлайн-дневник школы — версия для Chrome

Эта версия открывается как обычный сайт в Google Chrome. Сервер Express сам отдаёт страницу, поэтому отдельное открытие `frontend/index.html` больше не требуется.

## Роли
- Директор: классы, учителя, предметы, ученики и назначения учителей.
- Учитель: видит назначенные классы и ставит оценки.
- Ученик: видит свои оценки и средний балл.

## Онлайн-размещение
Проект подготовлен для размещения на облачном Node.js-хостинге (например, Render) с PostgreSQL. На компьютере pgAdmin для самой страницы не нужен; база данных всё равно должна быть размещена в облаке.

## Переменные окружения
`PORT` — порт сервера.
`DATABASE_URL` — адрес PostgreSQL.
`JWT_SECRET` — секрет для токенов.
